## 📋 Descripción del Proyecto

Aplicación interactiva de consola desarrollada en Java que implementa la lógica clásica del juego de adivinar un número aleatorio dentro de un rango configurable. Cuenta con un menú interactivo con selección de dificultad, pistas en tiempo real (*más alto* o *más bajo*), control de intentos y validación robusta de excepciones para evitar cierres inesperados por entradas incorrectas.

---

## 🛠️ Requisitos Técnicos Implementados

- **Estructuras de control:** Uso de `if-else`, `switch-case`, bucles `while` y `do-while`.
- **Entrada/Salida:** Manejo de la clase `Scanner` y formateo de mensajes en consola.
- **Programación Orientada a Objetos (POO):** Clases estructuradas bajo el paquete `juego` aplicando encapsulamiento, constructores, atributos privados y métodos de lógica de negocio.
- **Manejo de Excepciones:** Uso de bloques `try-catch` para capturar `InputMismatchException` ante ingresos no numéricos.
